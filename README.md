# CET-4 Reader

大学英语四级精读工具。文章、学习记录和阅读位置保存在当前浏览器。

## 功能

- 单击 / 双击英文单词直接查中文
- 鼠标拖选短语后直接翻译
- 点击单词后自动翻译所在整句，便于结合上下文判断词义
- 一键重新翻译当前整句
- 自动记录“今天查过的词”
- 独立生词本
- 错题 / 难句记录，并按词汇、长难句、定位、推理、主旨、选项辨析分类
- 文章按仔细阅读、长篇匹配、选词填空、听力原文等分类
- 10 / 15 / 40 分钟四级阅读计时器
- 自动保存文章阅读位置、字号、文章、生词和错题

## 翻译方式与范围

单词优先查同源 ECDICT 学习词典；明确的固定搭配使用内置搭配释义。词典列出的是常用含义，不能自动断定哪个义项适合当前语境。

整句及词典未收录的查询按以下顺序处理：

1. 支持的浏览器使用 [Translator API](https://developer.chrome.com/docs/ai/translator-api)。首次启用可能下载语言模型，页面显示准备状态；模型准备不会阻塞整句查询。
2. 本机翻译不可用时尝试 Google 翻译的公开网页客户端接口。此接口不是具有服务保证的正式 Cloud Translation API，可能限流、受网络影响或变更；对限流响应不会自动反复重试。
3. 在线请求失败时尝试原站已有的 Lingva 实例。每次仅尝试两个备用实例，失败后由用户决定是否重试。

翻译显示来源和明确失败状态。未获得有效中文时不会展示伪造结果；可点击必应或 Google 的原文对照链接自行核对。机器译文仍可能在语境、否定、术语等方面出错，本次改进不构成准确率保证。

本机词典查词仅加载本站数据。在线翻译会向相应服务发送查询文本或所在完整句子；关闭“自动翻译所在句”后仅在主动查询或点击“译整句”时发送。学习记录不会作为整批数据上传。未添加需要用户填写 API 密钥的功能。

## 本地运行与验证

需要 Node.js 18 或更新版本。

```sh
npm start
# 打开 http://127.0.0.1:4173

npm test
node scripts/build-dictionary.mjs --verify

# 浏览器测试需要 Playwright 和 Chromium
npm install
npx playwright install chromium
npm run test:browser
```

也可设置 BROWSER_EXECUTABLE 使用本机 Chromium 系浏览器。浏览器测试包括真实本地词库查询，并在并发测试中使用可控译文模拟慢请求；这些测试不声称测量线上翻译准确率。

项目为静态站点，无构建步骤。发布文件包括 index.html、styles.css、text-utils.js、translation-engine.js、app.js、.nojekyll 以及 data/ 下的词典、来源和许可证。保持原 GitHub Pages 地址与浏览器存储键，既有学习数据可继续使用。

词典数据及可复现构建方式见 [data/README.md](data/README.md)，第三方声明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

# CET-4 Reader

一个用于大学英语四级精读的浏览器工具。

## 功能

- 单击 / 双击英文单词直接查中文
- 鼠标拖选短语后直接翻译
- 点击单词后自动翻译所在整句，便于结合上下文判断词义
- 一键重新翻译当前整句
- 自动记录“今天查过的词”
- 独立生词本
- 错题 / 难句记录，并按词汇、长难句、定位、推理、主旨、选项辨析分类
- 文章按仔细阅读、长篇匹配、选词填空、听力原文等分类
- 10 / 15 / 40 分钟四级阅读计时器
- 自动保存文章阅读位置、字号、文章、生词和错题

## 翻译策略（准确性优先）

1. 单个单词优先使用核心词义、CET-4、CET-6、高频基础词、Oxford 5000 等多词库整合，优先展示常见义项和音标。
2. 短语与整句优先使用桌面 Chrome 的 Translator API，在支持的浏览器上由浏览器本地模型翻译。
3. 浏览器不支持 Translator API 时，尝试 Lingva 公共 API 作为跨浏览器备用方案。
4. 不再自动回退到 MyMemory。高质量引擎均不可用时直接提示不可用，避免给出明显生硬或错误的译文。

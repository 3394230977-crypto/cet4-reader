# CET-4 Reader

一个用于大学英语四级精读的浏览器工具。

## 功能

- 单击 / 双击英文单词直接查中文
- 鼠标拖选短语后直接翻译
- 一键翻译当前整句
- 自动记录“今天查过的词”
- 独立生词本
- 错题 / 难句记录，并按词汇、长难句、定位、推理、主旨、选项辨析分类
- 文章按仔细阅读、长篇匹配、选词填空、听力原文等分类
- 10 / 15 / 40 分钟四级阅读计时器
- 自动保存文章阅读位置、字号、文章、生词和错题
